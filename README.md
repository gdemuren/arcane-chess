# Arcane Chess

A refined, responsive chess game for the browser. Play locally with a friend, race the ten-minute clocks, and take on the daily opening spark.

## Play locally

Open `index.html` in any modern browser. No install, account, or dependencies needed.

## Features

- Local two-player chess with legal move and check protection
- Ten-minute chess clocks
- Move history, undo, board flip, and pawn promotion to queen
- Responsive design for desktop and mobile

## Publish with GitHub Pages

After putting these files in a public GitHub repository, open **Settings → Pages**, choose **Deploy from a branch**, and select `main` and `/ (root)`. Your game will be available at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.
